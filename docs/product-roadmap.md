# 产品路线与维护边界

本文用于替代原先分散的 To C 产品规划、用户故事、页面线框、设计 brief 和 Web 重构计划。详细接口、表结构、运行配置以代码、迁移文件和专题文档为准；历史过程记录统一查 `docs/CHANGELOG.md`。

## 当前产品定位

DSA 面向个人投资者和小团队，核心是把 A 股、港股、美股的行情、新闻、技术指标和 LLM 分析组合成可追踪的决策报告。Web 工作台是主要入口，Bot、CLI、调度任务和桌面端作为补充入口。

## 已落地能力

- 多用户账号体系：邮箱注册、登录、验证、找回密码、Session、管理员角色。
- 数据隔离：历史报告、分析任务、投资组合、告警、Agent 会话按当前用户隔离。
- 套餐与配额：分析和 Agent 问股接入 quota guard，超限返回统一升级引导。
- 自选股与通知：用户自选股、通知偏好、Pro 邮件/每日推送/Webhook、一键退订。
- 商业化骨架：套餐、订单、支付、退款、发票、运营后台、对账脚本和审计日志。
- Web 工作台：分析、问股、历史报告、任务中心、提醒、账户、会员、研报和帮助中心。

## 近期维护重点

- 保持 Web 首屏、分析提交、任务进度、报告阅读和账号/账单链路稳定。
- 支付通道生产小额端到端验证，确认真实商户号、证书、回调和退款链路。
- 按用户维度完善调度限流和 provider rate limit 保护，避免多用户定时任务相互影响。
- 继续收敛帮助中心、设置页提示和专题文档，避免 README 与长文档重复膨胀。
- 运营确认套餐分档、模型白名单、积分包、邀请奖励和公告/邮件触达策略后再扩展。

## 设计与交互原则

- 首页直接提供可用的股票分析工作台，不做营销式落地页。
- 复杂能力放在任务面板、账户页、设置页和帮助中心，避免首页承载过多说明。
- 数据表、报告、账单、配额等高频页面优先清晰、紧凑、可扫描。
- 移动端保留核心分析、报告阅读、登录注册、账户和账单流程；复杂运营后台优先桌面端。
- 投资建议相关文案必须保持风险提示，避免承诺收益或暗示确定性操作。
