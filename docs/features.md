# 功能说明

## 核心分析

单股分析以股票代码或名称为输入，收集行情、K 线、技术指标、基本面、资金、新闻与公告等上下文，再由分析管道生成结构化结论和 Markdown 报告。报告用于辅助判断，数据缺失、数据源降级和模型不确定性都会在结果中影响结论质量。

大盘复盘是独立的市场级任务，输出主要指数、市场宽度、热点与风险观察。它不能替代单股分析。

## Web 与桌面端

Web 是主要操作界面，提供首页分析、任务进度、历史报告、设置、组合、告警、选股、回测、研究报告和账户等页面。桌面端使用同一 Web UI，并负责本地安装、服务启动与更新体验；其打包脚本和构建方式见[开发指南](development.md)。

Web 路由与权限由后端认证状态共同控制。开启多用户模式后，报告、组合、告警和运行历史按用户隔离，系统设置和管理功能仅对有权限的用户开放。

## Agent 与对话

Agent 支持围绕股票和市场进行多轮问答。它会选择分析技能、市场数据、搜索和回测工具，在预算、步数和上下文限制内形成答案。对话历史可压缩为摘要以控制上下文开销；Agent 的结论同样是研究辅助，不应被当作交易指令。

## 智能情报与决策信号

系统可以从分析结果中提取结构化决策信号，用于后续跟踪、反馈、复评和结果归因。智能情报页面聚合可跟踪的分析线索和历史结果。信号评分反映模型与规则的当前判断，不保证未来表现。

## 组合、告警与通知

组合功能保存自选与持仓上下文；告警服务按规则检查价格、技术指标和组合风险，并在满足条件时交给通知服务。通知支持路由、静默时段、严重程度、去重和冷却时间。单个通知渠道失败会记录诊断信息，正常情况下不会终止主分析任务。

## 选股与回测

选股引擎先从市场快照进行硬过滤、因子评分、风险调整和排序，再对候选集进行上下文补充与可选的 LLM 重排。数据源、快照和缓存会影响候选结果，选股结果不代表推荐。

回测用于检查策略在历史数据上的表现。历史表现受样本区间、复权方式、交易成本、数据完整性和幸存者偏差影响，不能直接外推为未来收益。

## Bot 与外部接入

`backend/bot/` 提供飞书、钉钉、Discord 等平台接入，Bot 请求经 Webhook 或流式连接进入统一分发器，再触发分析、问股或查询流程。外部平台的签名校验、回调地址和网络暴露必须按各平台文档配置；公网部署先完成 HTTPS 和鉴权。
